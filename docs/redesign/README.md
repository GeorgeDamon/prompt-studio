# Prompt Studio：简洁文本版

2026-11-03。基于上游 `linshenkx/prompt-optimizer` 的 `develop` 分支，基线提交 `a4c1934`（v2.14.0）。

## 本轮完成

Web 端采用 ChatGPT 风格的侧栏与居中编辑区。浅色界面、系统字体、柔和边框与圆角，提供「日常指令」和「角色设定」两个文本工作区。

保留原有文本优化、继续优化、版本、复制、历史、收藏、文本模型配置与数据备份。新增写作、编程、学习示例，以及侧栏新建入口。示例仅填入编辑器，不会自动调用模型。

精简版不再提供图片生成、高级变量/多轮测试、Function Calling 工作区、对比测试、分析和评估入口。文本工作区不渲染测试面板和评估面板；模型管理不挂载图片模型与功能模型界面。旧图片和高级模式链接会返回文本工作台。

手机侧栏可折叠；关闭时不可被键盘或读屏访问。展开时主内容暂不可交互，Escape 可关闭。

## 代码范围

- Web 入口为 `PromptOptimizerApp` 启用 `focus-mode`。
- `FocusLayout.vue` 提供精简版布局，`focus-workspace.css` 的规则限定在 `.focus-app` 内。
- 继续复用原工作区、模型服务、历史与收藏存储。当前主要完成界面与功能入口精简，上游高级功能的源文件和依赖仍保留，构建包尚未全面瘦身。
- 原始默认应用壳仍可供其他宿主使用。本轮没有改造桌面安装包或浏览器扩展，也没有发布、提交或推送。
- 界面暂以中文为主，新增文案尚未纳入完整多语言翻译。

## 本地运行

上游要求 Node.js `^24.22.1`，包管理器为 pnpm `10.6.1`。按上游环境安装后可执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

本次机器的 Node 为 24.21.0，依赖安装跳过生命周期脚本；通过单次命令参数 `--config.engine-strict=false` 进行构建和预览，没有修改上游引擎要求。以上构建、类型与测试检查在该环境中通过。

当前本地预览地址：<http://127.0.0.1:18181/>。开发服务关闭后需要重新启动。
